# erlangb

`erlangb` — консольная утилита для расчётов по формуле **Эрланга B**, используемой в теории телетрафика для оценки вероятности потерь вызовов в системе с ограниченным числом каналов.

Программа принимает на вход различные комбинации параметров и вычисляет недостающие значения.

# сборка
```
git clone https://github.com/tagiev001/Erlang-B-calc
cd Erlang-B-calc
gcc erlangb.c -o erlangb
---

## Параметры

Утилита поддерживает следующие аргументы командной строки:

- `-h`  
  Показать справочное сообщение

- `-a <number>`  
  Нагрузка (Load), `a > 0`

- `-v <number>`  
  Количество каналов (целое число)

- `-m <number>`  
  Среднее число занятых каналов

- `-E <number>`  
  Вероятность потерь (доля потерянных заявок), `0 < E < 1`

---

## Поддерживаемые режимы работы

Программа принимает **две величины** и вычисляет остальные:

- `-a <number> -v <number>` → вычисляет `E`, `m`
- `-a <number> -E <number>` → вычисляет `v`, `m`
- `-a <number> -m <number>` → вычисляет `v`, `E`
- `-v <number> -m <number>` → вычисляет `a`, `E`
- `-E <number> -m <number>` → вычисляет `a`, `v`
