# erlangb

`erlangb` — консольная утилита для расчётов по формуле **Эрланга B**, используемой в теории телетрафика для оценки вероятности потерь вызовов в системе с ограниченным числом каналов.

Программа принимает на вход различные комбинации параметров и вычисляет недостающие значения.

## Сборка

```bash
git clone https://github.com/tagiev001/Erlang-B-calc
cd Erlang-B-calc
gcc -Wall -Wextra -O2 erlangb.c -o erlangb -lm
```

Флаг `-lm` (математическая библиотека) должен стоять **после** имени исходного файла.

---

## Параметры

| Параметр | Описание | Ограничения |
|---|---|---|
| `-h` | Показать справочное сообщение | используется отдельно |
| `-a <число>` | Нагрузка (Load), в Эрлангах | `a > 0` |
| `-v <число>` | Количество каналов | целое, `1 ≤ v ≤ 1000000` |
| `-m <число>` | Среднее число занятых каналов | `m > 0` |
| `-E <число>` | Вероятность потерь (доля потерянных заявок) | `0 < E < 1` |

Дополнительные условия: при использовании `-m` должно выполняться `m < a` (вместе с `-a`) или `m < v` (вместе с `-v`).

---

## Поддерживаемые режимы работы

Программа принимает **ровно две различные величины** (в любом порядке) и вычисляет остальные:

| Входные данные | Результат |
|---|---|
| `-a <число> -v <число>` | `E`, `m` |
| `-a <число> -E <число>` | `v`, реальные потери `E`, `m` |
| `-a <число> -m <число>` | `v`, `E` |
| `-v <число> -m <число>` | `a`, `E` |
| `-v <число> -E <число>` | `a`, `m` |
| `-E <число> -m <число>` | `a`, `v` |

### Замечание про `E` в режиме `-a -E`

Число каналов целое, поэтому реальные потери почти никогда не совпадают с заданными. Заданное `E` — это **допустимый** уровень потерь: программа находит наименьшее `v`, при котором потери не превышают `E`. Среднее число занятых каналов `m` считается по **реальным** потерям для найденного `v`, поэтому они выводятся отдельной строкой.

## Примеры использования

### Нагрузка и число каналов

```bash
./erlangb -a 10 -v 5
```

```
Percentage of lost 0.563952
Average number of busy channels: 4.360478
```

### Нагрузка и допустимые потери

```bash
./erlangb -a 40 -E 0.01
```

```
Required number of channels: 53
Real percentage of lost: 0.008227
Average number of busy channels: 39.670915
```

### Число каналов и допустимые потери

```bash
./erlangb -v 50 -E 0.01
```

```
Load: 37.901398
Average number of busy channels: 37.522384
```

### Число каналов и среднее число занятых каналов

```bash
./erlangb -v 50 -m 39.6
```

```
Percentage of lost: 0.021045
Load: 40.451283
```

## Обработка ошибок

При некорректном вводе (неизвестная опция, нет значения, не число, значение вне допустимого диапазона, лишние аргументы) программа выводит `Invalid input`, справку и завершается с кодом `1`. Запуск без аргументов или с `-h` выводит справку и завершается с кодом `0`.

## Тесты

```bash
bash test_erlangb.sh                # соберёт erlangb.c и запустит проверки
bash test_erlangb.sh ./erlangb      # или использует готовый бинарник
```

Тесты покрывают все режимы, граничные и некорректные значения, перекрёстную проверку с точной формулой Эрланга B и устойчивость на больших значениях. Для перекрёстной проверки нужен `python3`; без него эта часть пропускается.
